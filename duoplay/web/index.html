Consoles

Looking for consoles on your network… The PS5 needs to be on, or in rest mode with Stay Connected to the Internet and Enable Turning On PS5 from Network switched on, and Remote Play enabled under Settings → System → Remote Play.

Try it without a console

A small arena game runs in the picture area so you can try the controls, folding and unfolding, and the half-folded handheld mode.

Connecting to your PS5

Safari can't open the kind of network connection a PS5 uses, so DuoPlay reaches the console through a small bridge at home. A Raspberry Pi Zero W does the job, and you can set it up from this phone:

  1. Download the SD-card kit, unzip it in Files and copy what's inside onto the Pi's microSD card.
  2. Start the Pi. Join the DuoPlay Setup Wi-Fi and pick your home network on the page that opens.
  3. Open http://duoplay.local:8080 in Safari and add DuoPlay to your Home Screen from there.

Install DuoPlay

Tap Share, then Add to Home Screen, and leave Open as Web App on. DuoPlay then launches full screen like any app, on both screens, with no browser bars and no edge swipes that leave the game.

Turn on controllers and keep the screen awake

Safari only allows Bluetooth controllers and screen wake lock on a secure page. Install the bridge's certificate once:

  1. Download the certificate, then Settings → Profile Downloaded → Install.
  2. Settings → General → About → Certificate Trust Settings: switch on DuoPlay Local CA.
  3. Open DuoPlay securely and add that page to the Home Screen.
