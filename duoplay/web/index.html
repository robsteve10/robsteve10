DuoPlay

Turn on controller support

Safari only lets web pages use game controllers and keep the screen awake on a secure (HTTPS) page. Install the bridge's certificate once:

  1. Download the certificate, then open Settings → Profile Downloaded and install it.
  2. Open Settings → General → About → Certificate Trust Settings and switch on DuoPlay Local CA.
  3. Open DuoPlay over HTTPS and add that page to your Home Screen.

Add DuoPlay to your Home Screen

Tap Share → Add to Home Screen. It then opens full screen with no browser bars, so the picture and controls get every pixel on both screens, and edge swipes can't navigate you away mid-game.
